## 서술어군
: 문장의 본질로, 함을 나타내는 어휘군

서술어 말끝 기본형은 <span class="serif-text"> 갓 </span> 의 꼴을 지닌다.
서술어의 말끝은 시간에 따라, 상태에 따라, 방향에 따라 말 끝이 바뀐다.
#### 시간
{과거} {현재} {미래}
위와 같은 세개의 시제를 가진다.
#### 상태
{완료} {진행} {단순}
#### 방향
{하는} {당하는}

## 말끝
: 서술어의 특성에 따라 말끝의 형태가 달라짐.

모든 서술어는 <span class="serif-text"> 갓 </span>의 꼴로 끝이나며, 이를 말끝이라 칭함.

#### 시간
: <span class="serif-text">갓</span>의 <span class="serif-text">ㄱ</span>에 해당하는 초성을 조정.

말하는 시점을 기준으로, 과거;현재;미래 로 구분된다.

시제는 말끝 초성의 성격을 결정한다. 
{과거} : 경음화된 초성
{현재} : 기본 초성
{미래} : 격음화된 초성

ex ) <span class="serif-text">갓</span>
과거 : <span class="serif-text">깟</span>
현재 : <span class="serif-text">갓</span>
미래 : <span class="serif-text">캇</span>

또한, 말끝의 초성에 사용되는 자음은 경음과 격음이 모두 존재하는 자음으로 한다.
즉, ㄱ,ㄴ,ㅁ,ㅈ 에 한정한다.
ㅇ은 기본자이지만 초성의 부재로 간주하여 사용하지 않는다.
ㅅ은 기본자이지만 격음화의 결과 자음이 부재하여 사용하지 않는다.

#### 상태
: <span class="serif-text">갓</span>의 ㅅ에 해당하는 종성을 조정.

단순;완료;진행으로 구분한다.
