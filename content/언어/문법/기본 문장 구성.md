# 개요
새로운 언어의 기본적인 문법을 소개하는 문서.

문장을 정의하는 가장 핵심적인 말은 서술어이다.
서술어가 존재하는 어휘 묶음을 문장,
서술어가 존재치 않는 어휘 묶음을 절 이라 칭한다.

# 문장 어휘
### 어휘 군
서술어와의 관계에 따른 어휘 분류

어휘군은 문장에서의 중요도에 따라 분류한 묶음이다.

- 0군 - 절대 필수적인 어휘군
	- 서술어군
		행위를 지칭하는 어휘군

- 1군 - 필수적이나 없는 것이 허용되는 어휘군
	- 주체어군
		서술어를 행하는 주체를 칭하는 어휘군
	- 대상어군
		서술어의 대상이 되는 객체를 칭하는 어휘군
	- 객체어군
		서술어를 당하는 객체를 칭하는 어휘군

- 2군 - 많은 경우 없어도 되나 일부 경우 필수적인 어휘군
	- 관계어군
		다른 어휘와의 관계를 가지는 어휘군

- 3군 - 없어도 되는 선택적인 어휘군
	- 특성어군
		다른 어휘의 특성을 설명하는 어휘군.

- 4군 - 서술어와 관계가 없는 어휘군
	- 음성어군 - 단순한 소리 혹은 감탄을 표하는 어휘군

### 어휘의 방향
서술어와의 관계에 따라 어휘군의 방향이 존재한다.

- 중심어 : 서술어
- 전방어 : 서술어를 행하는 원인과 조건 방향의 어휘
	- 주체어
- 후방어 : 서술어를 행하는 결과와 도구 방향의 어휘
	- 대상어
- 무방어 : 서술어의 방향과 큰 관련 없는 어휘
	- 객체어
	- 전향어 : 서술어가 아닌 어휘군의 **앞**에서 관계 잇는 어휘
		- 특성어
	- 후향어 : 서술어가 아닌 어휘군의 **뒤**에서 관계 잇는 어휘
		- 관계어
	- 무향어 : 아무 어휘군과도 관계 잇지 않은 어휘
		- 음성어

### 어순
기본적인 어순은 서술어를 중심으로 주변에 어휘들을 아래와 같이 배치한다.

이를 문장으로 구성하면 아래와 같은 구조가 된다.

(전향어)전방어(후향어) // 무방어-서술어 // (전향어)후방어(후향어) //// {무방어}

ex) (바쁜)어머니(of 아이) /가/ 밥먹이다 // (졸려하는)아이에게(of 어머니) //// 아
-=>아, 아이의 바쁜 어머니가 졸려하는 아이에게 밥을 먹인다.

위의 예시는 최대한 많은 요소를 사용한 문장으로, 자연스럽지는 않을 수 있다.
